### Atividade 3  Formulário de Cadastro

Foi desenvolvido um formulário para entrada e validação de informações.

O usuário pode inserir seu nome, selecionar a opção de aceite dos termos e enviar os dados. Após o envio, a aplicação apresenta uma mensagem personalizada.

**Funcionalidades:**

- Campo para nome completo
- Entrada de dados
- Checkbox para aceite dos termos
- Botão de envio
- Validação do campo
- Mensagem de retorno ao usuário

### Atividade 4 Mercado do Mago

Nesta atividade foi desenvolvida uma aplicação para cadastro e controle de itens.

**Funcionalidades:**

- Campo para inserção do nome do item
- Validação do campo
- Adição dinâmica de itens

## Como Executar

### 1. Instalar o Python

Verifique se o Python está instalado na máquina:

```bash
python --version
```

### 2. Instalar o Flet

No terminal, execute:

```bash
pip install flet
```

### 3. Clonar o repositório

```bash
git clone https://github.com/PaollaVeronez05/Atividade_Python_Flet.git
```

### 4. Acessar a pasta do projeto

```bash
cd Atividade_Python_Flet
cd Flet
```

### 5. Executar as atividades

```bash
# Primeira atividade
python ativ1.py

# Segunda atividade
python ativ2.py

# Terceira atividade
python ativ3.py

# Quarta atividade
python ativ4.py
```
